# RC Adventure Hub

A static affiliate site for RC cars, planes, and boats, built for adult hobbyists.
No server required -- it's plain HTML/CSS generated by a small Python script,
so it can be hosted for free and will load fast.

```
content/       Articles & pages (Markdown + YAML frontmatter) -- edit these
data/          config.yaml (site + affiliate IDs) and products.yaml (link catalog)
templates/     Jinja2 HTML templates -- edit these to change the design
static/        CSS (and later, images)
build.py       Generates the site into dist/
dist/          The finished, deployable website (generated -- don't hand-edit)
automation/    Notes on the ongoing content pipeline
```

## Building the site locally

```bash
pip install --break-system-packages markdown pyyaml jinja2   # first time only
python3 build.py
```

That regenerates everything in `dist/`. To preview it in a browser:

```bash
cd dist && python3 -m http.server 8000
# then open http://localhost:8000
```

(Opening `dist/index.html` directly by double-clicking it will look unstyled --
the CSS uses root-relative paths like `/static/...`, which only resolve
correctly when served over http, not `file://`. This is normal and is exactly
how the file will behave once deployed for real.)

## Adding a new article

1. Add any new products it mentions to `data/products.yaml`.
2. Create a new file in `content/`, copying the frontmatter style of an
   existing article (`title`, `slug`, `category`, `meta_description`, `date`,
   `products`).
3. Write the body in Markdown. Drop a product recommendation card anywhere
   with `{{product:the-product-id}}`.
4. Run `python3 build.py`.

## Everything this project still needs from you

I (Claude) can write code, content, and scripts, but the steps below involve

### 1. A domain name (~$10-15/year)
Any registrar works (Namecheap, Porkbun, Cloudflare Registrar are all
reasonable and cheap). Avoid GoDaddy's upsells if you'd rather not deal with
them. Once you have one, put it in `data/config.yaml` under `site.url`.

### 2. Free hosting
Since this is a static site, you don't need to pay for hosting. Good free
options, easiest first:
- **Cloudflare Pages** -- connect a GitHub repo, it builds and deploys on
  every push, free custom domain support.
- **Netlify** -- same idea, also free, also easy.
- **GitHub Pages** -- free, slightly more manual, works fine too.

All three want your code in a **GitHub repository**. If you don't have a
GitHub account yet, create one (free) at github.com, then create a new repo
and push this project to it:

```bash
cd rc-hobby-hub
git init
git add .
git commit -m "Initial site"
git branch -M main
git remote add origin https://github.com/YOUR-USERNAME/rc-adventure-hub.git
git push -u origin main
```

Then connect that repo in Cloudflare Pages / Netlify, set the build command
to `pip install -r requirements.txt && python3 build.py` and the output
directory to `dist`, and point your domain at it. Tell me once this is done and I can help troubleshoot the
deploy config or take it from here if you give me repo access.

### 3. Affiliate program applications
Apply in this order -- Amazon is fastest to get an account (though it takes
3 sales in 180 days to stay approved), the others pay noticeably better once
approved:

| Program | Where | Commission | Notes |
|---|---|---|---|
| Amazon Associates | affiliate-program.amazon.com | ~3% on toys/hobby | Apply once the site is live with real content -- they review the site. |
| AvantLink | avantlink.com | Horizon Hobby 3-5%, AMain Hobbies 5% (+1% new customer) | Runs the Horizon Hobby & AMain Hobbies programs. Approval isn't instant. |
| ShareASale | shareasale.com/newsignup.cfm | Genstattu 6-8%, Bezgar 10-15% | Higher commissions, smaller/newer brands. |

Once approved, put your Amazon tracking ID and AvantLink/ShareASale IDs into
`data/config.yaml`, and for AvantLink/ShareASale products, generate the real
tracking link from that network's "Link Generator" tool and paste it into
that product's `affiliate_url_override` field in `data/products.yaml`. See
`automation/AVANTLINK_SETUP.md` for the exact steps.

Until you do this, every "Check Price" button on the site already works and
points somewhere real (Amazon search or the retailer's own search) -- you
just won't earn commission until the real IDs are in place.

### 4. Legal pages
`content/privacy-policy.md` and `content/about.md` have `[bracketed]`
placeholders. Fill those in -- particularly run the privacy policy through a
proper generator (e.g. termly.io has a free tier) once you know what
analytics tool you'll use, since requirements genuinely vary by where your
visitors are located.
